Ember Canyon is a 3D sunset flight game: fly the little bush plane Kestrel down a golden canyon valley, thread all eight glowing rings in order, watch your fuel and the canyon walls, then land on the runway strip. It has a chase camera, a full instrument HUD (altitude, speed, heading, throttle, fuel, attitude), keyboard and mouse steering, procedural engine and wind sounds, three lives, and a seeded procedural world so every flight is the same valley.

## Run it

```sh
python3 -m http.server 8080 --directory game
```
